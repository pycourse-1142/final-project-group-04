##  一、專題規劃 (5/27 提交)
* **專題名稱**：捷運核心車站上下班尖峰時段人潮擁擠度與運量分流效率分析系統
* **資料來源**：臺灣政府資料開放平台 - 「臺北捷運各站分時進出量統計」(https://data.gov.tw/dataset/128506)
* **主要問題**：<br>
     1.讀取並解析特定月份數據中，各捷運車站在「早尖峰（07:00-09:00）」與「晚尖峰（17:00-19:00）」的每小時進出站人次。<br>
     2.經由核心運算進行分組與排序，找出「尖峰時段人流負荷最大」與「進出站人流最不平衡」的 Top 5 核心車站並進行排名。<br>
* **次要問題**：<br>1.原始數據中的進出車站名稱常帶有線別編號，如何透過字串處理或正規表示式精準剝離編號，以便與其他站點名冊進行對應分群與統計？<br>
               2.原始 CSV 檔案中若因跨月或系統異常出現空行、文字欄位錯亂，程式應如何設計防禦性邏輯，自動跳過或補值，確保執行時不崩潰。<br>
               3.確保「尖峰時段定義」與「Top 5 排序數量」設計為可隨時修改的變數參數。
* **預期產出圖表**：<br>1.早尖峰進站人數橫條圖： 核心車站早尖峰「進站人次」Top 5 排行。<br>
                   2.晚尖峰出站人數橫條圖： 核心車站晚尖峰「出站人次」Top 5 排行。<br>
                   3.每小時人流變化折線圖： 樞紐車站(多條路線交會，人流量大的車站) 24 小時進出站人潮的波動曲線。<br>
                   4.進出站平衡度散佈圖： X 軸為總進站數、Y 軸為總出站數，用以評估各車站的單向通勤特性。
